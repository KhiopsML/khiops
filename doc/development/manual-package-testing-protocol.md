# Manual Package Testing Protocol

The following checklists describe the manual tests to perform on Khiops packages before release.
Variants for each step are listed as sub-bullets.

Report the result of each step as one of the following:
- OK
- OK with a warning:
  - The step succeeds, but unexpected behavior occurs or a pop-up appears.
    - Consider adding a warning to the installation guide or troubleshooting section.
- Not OK (KO):
  - Provide as much context as possible to help developers reproduce the problem.

## Windows

Perform the checklist on the following system combinations:

Operating system versions:
- Windows 10
- Windows 11

Machine types:
- Personal or home computers
- Orange IT computers

### Checklist

- Check that the download link on https://khiops.org works correctly:
  - In Chrome
  - In Edge
  - In Firefox
- Run the installer:
  - By right-clicking the installer and selecting **Run as administrator**
  - By double-clicking the installer executable as a standard user (this is not equivalent to running it as an administrator)
    - Check that it is signed by Orange and is not identified as "Unknown Publisher"/"Editeur Inconnu".
- Select the installation directory:
  - the default `C:\Program Files\khiops`
  - one within the user's home directory (e.g., `C:\Users\<USERNAME>\khiops`)
  - another directory (e.g., `C:\Temp\khiops` or `C:\Applications\khiops`)
- Launch the Khiops applications:
  - From the Start menu
  - From the desktop icon
  - From the shortcut in the installation directory
- Check the tool version and copyright year (e.g., 2024) in the application and its documentation:
  - In the application menu: `Help > About Khiops...`
  - In the text files in the installation directory: `LICENSE.txt`, `README.txt`, and `WHATSNEW.txt`
  - In the PDF documents in the installation directory's `doc` subdirectory: guides and tutorials
- In the application, check that:
  - The **Open Dictionary File...** menu opens in `C:\Users\Public\khiops_data\samples`
  - A supervised analysis of `Adult` runs successfully
  - The resulting `AllReports.khj` file works correctly with Khiops Visualization
- Uninstall the application:
  - From the Start menu
  - From **Apps & Features** / **Applications et Fonctionnalités** in Settings
- Check that the following files and directories were removed:
  - The installation directory
  - The `C:\Users\Public\khiops_data\samples` directory
    - Also check that any files generated by a user during the `Adult` analysis were not removed.
- Install and reinstall the application:
  - Uninstall everything, if necessary.
  - Install the application using any of the methods above.
  - Install it again:
    - In the same directory
    - In another directory
  - Check that:
    - A pop-up stating "Khiops is already installed" appears; accept it.
    - When installing to another directory, the previous installation is removed.

## Linux and macOS

Perform the checklist on all supported operating systems.

### Checklist

- Install the application using the appropriate method for each operating system.
- Launch the Khiops applications:
  - From the application menu
  - From the desktop icon, if available
- In the application, check that:
  - The **Open Dictionary File...** menu opens in `/usr/bin` (?)
  - A supervised analysis of `Adult` runs successfully
  - The resulting `AllReports.khj` file works correctly with Khiops Visualization
- Uninstall the application.
- Check that the following files were removed:
  - The `MODL*`, `khiops`, `khiops-env`, and `khiops-coclustering` files from `/usr/bin`
  - `norm.jar` and `khiops.jar` from TBD
